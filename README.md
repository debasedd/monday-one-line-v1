`u-zeroxfive-monday-reviewed-in-one-line-e55de3c1` — "Monday, Reviewed in One Line".

The program writes the funniest one-line review of my own Monday to `/output/entry.txt` (100 characters, one line, no title, no explanation):

**My Monday showed up uninvited, ate the weekend's leftovers, and left its meetings all over my couch.**

The joke treats Monday as an unwanted houseguest: it shows up uninvited, eats the weekend's leftovers, and leaves its meetings all over the couch.

## Run it

```sh
python3 main.py
```
